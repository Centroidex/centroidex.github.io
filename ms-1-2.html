MS-1.2

Relaciones volumétricas: relación de vacíos, porosidad y grado de saturación

Ing. CivilPropiedades índice y relaciones de fases
Al terminar este tema podrásCalcular la relación de vacíos, la porosidad y el grado de saturación, y pasar de una a otra.

1Lo esencial

Tres relaciones entre volúmenes

La relación de vacíos e compara el volumen de vacíos con el de sólidos. Es la relación más usada en mecánica de suelos porque el volumen de sólidos no cambia cuando el suelo se comprime: lo que cambia es el vacío. Puede ser mayor que 1 en arcillas blandas.

La porosidad n compara el volumen de vacíos con el volumen total; siempre está entre 0 y 100 %. El grado de saturación Gw (en Das, S) dice qué fracción del vacío ocupa el agua: 0 % en un suelo seco y 100 % en uno saturado.

Cómo se relacionan e y n

Como ambas usan el volumen de vacíos, una se obtiene de la otra: n = e/(1 + e) y e = n/(1 − n). Un truco útil es suponer Vs = 1: entonces el vacío vale e y el volumen total 1 + e.

Relación de vacíose = Vv / Vs
Porosidadn = Vv / Vm = e/(1 + e)
Grado de saturaciónGw = Vw / Vv × 100

2Ejemplo resuelto

Con los volúmenes del tema MS-1.1 (Vs = 58.96 cm³, Vw = 27 cm³, Va = 14.04 cm³, Vm = 100 cm³), calcula e, n y Gw.

  1. Datos
    Vs = 58.96 cm³Vw = 27 cm³Va = 14.04 cm³Vm = 100 cm³
  2. Fórmula
    Vv = Vw + Vae = Vv/Vsn = Vv/VmGw = Vw/Vv
  3. Sustitución
    Vv = 27 + 14.04 = 41.04 cm³e = (41.04 cm³)/(58.96 cm³) = 0.696n = (41.04 cm³)/(100 cm³) × 100 = 41.0 %Gw = (27 cm³)/(41.04 cm³) × 100 = 65.8 %Comprobación: n = 0.696/(1 + 0.696) = 41.0 % ✓
  4. Resultado
    e = 0.696 · n = 41.0 % · Gw = 65.8 %
Error frecuenteCalcular la porosidad con el volumen de sólidos en el denominador. La porosidad usa el volumen total; la relación de vacíos, el de sólidos.
