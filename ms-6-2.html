MS-6.2

Prueba triaxial

Ing. CivilResistencia al esfuerzo cortante
Al terminar este tema podrásInterpretar una prueba triaxial con el círculo de Mohr y obtener el ángulo de fricción.

1Lo esencial

La prueba

Una probeta cilíndrica envuelta en membrana se somete a una presión de confinamiento σ3 en una cámara con agua; después se aumenta la carga axial hasta la falla. El esfuerzo principal mayor es σ1 = σ3 + Δσd, donde Δσd es el esfuerzo desviador. Cada prueba da un círculo de Mohr; la recta tangente a varios círculos es la envolvente de falla.

A diferencia del corte directo, en la triaxial se controla el drenaje y se puede medir la presión de poro, y el plano de falla no está forzado: forma un ángulo de 45° + φ/2 con la horizontal.

Tres tipos de prueba

UU (no consolidada, no drenada): rápida; en arcillas saturadas da φ = 0 y cu = Δσd/2, útil para el corto plazo. CU (consolidada, no drenada): se consolida con σ3 y se falla sin drenar, midiendo u. CD (consolidada, drenada): se falla tan lento que no se genera presión de poro; da los parámetros efectivos para el largo plazo.

Esfuerzo principal mayorσ1 = σ3 + Δσd
Con c = 0sen φ = (σ1 − σ3)/(σ1 + σ3)
Condición de fallaσ1 = σ3 tan²(45° + φ/2) + 2c tan(45° + φ/2)

2Ejemplo resuelto

Una arena se ensayó en triaxial CD con σ3 = 1.0 kgf/cm² y falló con un esfuerzo desviador de 2.7 kgf/cm². Calcula φ y el ángulo del plano de falla.

  1. Datos
    σ3 = 1.0 kgf/cm²Δσd = 2.7 kgf/cm²c = 0
  2. Fórmula
    σ1 = σ3 + Δσdsen φ = (σ1 − σ3)/(σ1 + σ3)θ = 45° + φ/2
  3. Sustitución
    σ1 = 1.0 + 2.7 = 3.7 kgf/cm²sen φ = (3.7 − 1.0)/(3.7 + 1.0) = 0.5745 → φ = 35.1°θ = 45° + 35.1°/2 = 62.5°
  4. Resultado
    φ = 35.1° · plano de falla a 62.5° de la horizontal
Error frecuenteUsar el esfuerzo desviador como σ1. El esfuerzo principal mayor es el desviador más el confinamiento.
