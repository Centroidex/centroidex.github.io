MS-1.3

Relaciones gravimétricas: pesos específicos

Ing. CivilPropiedades índice y relaciones de fases
Al terminar este tema podrásCalcular los pesos específicos de un suelo y distinguir cuándo se usa cada uno.

1Lo esencial

Cuatro pesos específicos

El peso específico natural γm es el peso de la muestra entre su volumen, tal como está en el terreno. El peso específico seco γd considera solo el peso de los sólidos: se usa para controlar la compactación y no depende del agua.

Si todos los vacíos se llenan de agua se tiene el peso específico saturado γsat. Bajo el nivel freático el agua empuja hacia arriba a las partículas, así que el suelo "pesa" menos: el peso específico sumergido γ′ = γsat − γ0 es el que se usa para calcular esfuerzos efectivos.

Unidades

En este curso los pesos específicos se dan en t/m³, que numéricamente es igual a g/cm³: el agua pesa γ0 = 1 t/m³. Así, si una muestra pesa 1.85 g/cm³, el suelo pesa 1.85 t/m³ en el terreno.

Natural y secoγm = Wm/Vm · γd = Ws/Vm = γm/(1 + w)
Saturadoγsat = (Ws + Vv γ0)/Vm
Sumergidoγ′ = γsat − γ0

2Ejemplo resuelto

Con la muestra de MS-1.1 (Wm = 185 g, Ws = 158 g, Vm = 100 cm³, Vv = 41.04 cm³), calcula γm, γd, γsat y γ′.

  1. Datos
    Wm = 185 gWs = 158 gVm = 100 cm³Vv = 41.04 cm³γ0 = 1 g/cm³
  2. Fórmula
    γm = Wm/Vmγd = Ws/Vmγsat = (Ws + Vv γ0)/Vmγ′ = γsat − γ0
  3. Sustitución
    γm = (185 g)/(100 cm³) = 1.85 g/cm³ = 1.85 t/m³γd = (158 g)/(100 cm³) = 1.58 t/m³Comprobación: γd = 1.85/(1 + 0.1709) = 1.58 t/m³ ✓γsat = (158 g + (41.04 cm³)(1 g/cm³))/(100 cm³) = 1.99 t/m³γ′ = 1.99 − 1.00 = 0.99 t/m³
  4. Resultado
    γm = 1.85 · γd = 1.58 · γsat = 1.99 · γ′ = 0.99 t/m³
Error frecuenteUsar γsat bajo el nivel freático al calcular esfuerzos efectivos. El empuje del agua ya se descuenta con γ′, o restando la presión de poro al esfuerzo total.

3Para practicar
