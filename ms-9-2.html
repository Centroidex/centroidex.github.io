MS-9.2

Capacidad de carga admisible: forma, nivel freático y factor de seguridad

Ing. CivilCapacidad de carga
Al terminar este tema podrásCalcular la capacidad de carga admisible de una zapata cuadrada o circular, considerando la posición del nivel freático.

1Lo esencial

Forma de la zapata

Para zapatas aisladas, Terzaghi ajustó la ecuación: en una cuadrada, qu = 1.3c Nc + q Nq + 0.4γB Nγ; en una circular de diámetro B, el último término es 0.3γB Nγ.

La capacidad admisible se obtiene dividiendo entre un factor de seguridad, usualmente 3: qadm = qu/FS. La carga que puede recibir la zapata es qadm por su área. En este curso no se calcula aparte el peso propio de la zapata: la carga de la columna se incrementa un 10 % para incluirlo.

Efecto del nivel freático

El agua reduce el peso efectivo del suelo. Si el NAF está arriba del desplante, la sobrecarga se calcula con γ′ en la parte sumergida y el último término también usa γ′. Si está en el nivel de desplante, solo el último término usa γ′. Si está a una profundidad d bajo el desplante menor que B, se usa γ̄ = γ′ + (d/B)(γ − γ′) en el último término; si d ≥ B, el agua ya no influye.

Cuadradaqu = 1.3c Nc + q Nq + 0.4 γ B Nγ
Circularqu = 1.3c Nc + q Nq + 0.3 γ B Nγ
Admisibleqadm = qu/FS · Qadm = qadm A

2Ejemplo resuelto

Una zapata cuadrada de 2.0 × 2.0 m se desplanta a 1.5 m en una arena (c = 0, φ = 30°) con γ = 1.8 t/m³ arriba del NAF y γsat = 2.0 t/m³ abajo. El NAF está al nivel de desplante. Con FS = 3, calcula qadm y la carga máxima de la columna.

  1. Datos
    B = 2.0 mDf = 1.5 mφ = 30° → Nq = 22.46Nγ = 19.13γ = 1.8 t/m³γ′ = 2.0 − 1 = 1.00 t/m³FS = 3
  2. Fórmula
    qu = q Nq + 0.4 γ′ B Nγ (NAF en el desplante, c = 0)qadm = qu/3Qadm = qadm B²Pcol = Qadm/1.1
  3. Sustitución
    q = (1.8)(1.5) = 2.70 t/m²qu = (2.70)(22.46) + 0.4(1.00)(2.0)(19.13) = 60.64 + 15.30 = 75.95 t/m²qadm = 75.95/3 = 25.32 t/m² = 2.53 kgf/cm²Qadm = (25.32 t/m²)(2.0 m)² = 101.3 tPcol = 101.3/1.1 = 92.1 t
  4. Resultado
    qadm = 2.53 kgf/cm² · la columna puede bajar hasta 92.1 t
Error frecuenteUsar γsat bajo el nivel freático. El término de peso del suelo debe usar el peso específico sumergido γ′.

3Para practicar

Ejercicio 1. Zapata circular de 1.5 m de diámetro en arena seca (c = 0, φ = 30°, γ = 1.8 t/m³) desplantada a 1 m. Calcula qu.Ver respuesta
qu = (1.8)(22.46) + 0.3(1.8)(1.5)(19.13) = 55.92 t/m²
Ejercicio 2. Repite el ejemplo si el NAF sube hasta la superficie. ¿Cuánto vale ahora qadm?Ver respuesta
q = (1.0)(1.5) = 1.5 t/m² → qu = 48.99 t/m² · qadm = 16.33 t/m²
Ejercicio 3. Una columna baja 60 t y el terreno tiene qadm = 20 t/m². ¿Qué lado necesita la zapata cuadrada?Ver respuesta
B = √(1.1 × 60/20) = 1.82 m → usar B = 1.85 m
