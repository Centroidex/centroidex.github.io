MS-6.1

Criterio de Mohr-Coulomb y prueba de corte directo

Ing. CivilResistencia al esfuerzo cortante
Al terminar este tema podrásObtener los parámetros de resistencia c y φ con los resultados de una prueba de corte directo.

1Lo esencial

Resistencia al esfuerzo cortante

El suelo falla cuando el esfuerzo cortante en algún plano alcanza su resistencia al corte. Según el criterio de Mohr-Coulomb, esa resistencia crece con el esfuerzo normal efectivo sobre el plano: τf = c + σ′ tan φ. La cohesión c es la resistencia sin esfuerzo normal y el ángulo de fricción interna φ mide cuánto aumenta con σ′.

En arenas limpias c ≈ 0 y φ va de unos 28° (sueltas) a más de 40° (compactas). En arcillas, los parámetros dependen de si la prueba permite drenar o no (MS-6.2). La resistencia al corte es la base de la estabilidad de taludes, el empuje de tierras y la capacidad de carga.

Prueba de corte directo

La muestra se coloca en una caja partida en dos. Se aplica una carga normal y luego se desplaza la mitad superior hasta la falla, midiendo la fuerza cortante máxima. Se repite con al menos tres esfuerzos normales y se dibujan los puntos (σ, τf): la recta que mejor los ajusta es la envolvente de falla. Su ordenada al origen es c y su pendiente, tan φ.

Mohr-Coulombτf = c + σ′ tan φ
Esfuerzos en la cajaσ = N/A · τ = T/A

2Ejemplo resuelto

Tres pruebas de corte directo en un suelo dieron: σ = 0.5 kgf/cm² con τf = 0.43 kgf/cm²; σ = 1.0 con 0.66; σ = 2.0 con 1.12. Obtén c y φ.

  1. Datos
    (0.5; 0.43)(1.0; 0.66)(2.0; 1.12) en kgf/cm²
  2. Fórmula
    Recta τf = c + σ tan φ ajustada por mínimos cuadrados
  3. Sustitución
    tan φ = 0.460 → φ = 24.7°c = 0.737 − (0.460)(1.167) = 0.200 kgf/cm²
  4. Resultado
    c = 0.20 kgf/cm² · φ = 24.7°
Error frecuenteTomar φ como la pendiente de la recta. La pendiente es tan φ; el ángulo se obtiene con el arco tangente.

3Para practicar

Ejercicio 1. Una arena tiene φ = 32° y c = 0. ¿Qué resistencia tiene con σ′ = 1.5 kgf/cm²?Ver respuesta
τf = 0.937 kgf/cm²
Ejercicio 2. Dos pruebas dieron (1.0; 0.80) y (3.0; 1.90) kgf/cm². Calcula c y φ.Ver respuesta
tan φ = 0.55 → φ = 28.8° · c = 0.25 kgf/cm²
Ejercicio 3. Con c = 0.30 kgf/cm² y φ = 20°, calcula τf para σ = 2.0 kgf/cm².Ver respuesta
τf = 1.028 kgf/cm²
