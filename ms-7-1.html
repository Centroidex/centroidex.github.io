MS-7.1

Talud infinito

Ing. CivilEstabilidad de taludes
Al terminar este tema podrásCalcular el factor de seguridad de un talud infinito con y sin flujo de agua.

1Lo esencial

Qué es un talud infinito

Se llama así a un talud muy largo en el que la superficie de falla es paralela a la superficie y está a una profundidad pequeña comparada con su longitud, como una capa de suelo sobre roca en una ladera. Basta analizar una dovela: su peso se descompone en una fuerza que la empuja a deslizar y otra normal al plano que moviliza la fricción.

El factor de seguridad es la resistencia disponible entre la que se necesita para el equilibrio. Para taludes se piden normalmente valores de 1.5 o más.

Tres casos

En un suelo granular seco (c = 0), FS = tan φ/tan β: no depende de la altura, y el talud es estable mientras β < φ. Si hay cohesión se suma un término que disminuye con la profundidad. Con flujo de agua paralelo a la superficie, el agua reduce el esfuerzo efectivo y el FS de una arena baja aproximadamente a la mitad: FS = (γ′/γsat) tan φ/tan β.

Suelo con c y φFS = c/(γ H cos²β tan β) + tan φ/tan β
Granular secoFS = tan φ/tan β
Granular con flujo paraleloFS = (γ′/γsat) tan φ/tan β

2Ejemplo resuelto

Una capa de suelo de 3 m de espesor sobre roca forma una ladera con β = 25°. El suelo tiene γ = 1.8 t/m³, c = 1.2 t/m² y φ = 22°. Calcula el factor de seguridad sin agua.

  1. Datos
    β = 25°H = 3 mγ = 1.8 t/m³c = 1.2 t/m²φ = 22°
  2. Fórmula
    FS = c/(γ H cos²β tan β) + tan φ/tan β
  3. Sustitución
    Término de cohesión = 1.2/((1.8)(3)(0.8214)(0.4663)) = 0.580Término de fricción = 0.4040/0.4663 = 0.866FS = 0.580 + 0.866 = 1.45
  4. Resultado
    FS = 1.45 ≥ 1.5: el talud es estable
Error frecuentePensar que en una arena seca un talud más alto es menos estable. En el talud infinito sin cohesión, el FS solo depende de φ y β.

3Para practicar

Ejercicio 1. Una arena seca con φ = 34° forma un talud de 26°. Calcula el FS.Ver respuesta
FS = 1.38
Ejercicio 2. La misma arena (γsat = 2.0 t/m³) en un talud de 20° con flujo paralelo a la superficie. Calcula el FS.Ver respuesta
FS = (0.50)(1.853) = 0.93
Ejercicio 3. Con los datos del ejemplo, ¿a qué profundidad del plano de falla el FS sería 1.0? Usa H = c/(γ cos²β (tan β − tan φ)).Ver respuesta
H = 13.0 m
